# Introduction

<IntroHero version="2" />

TCAdmin is the leading game server control panel, built to streamline game server hosting. It gives you comprehensive control over every server through a secure, efficient architecture and an interface that works for administrators and end users alike.

TCAdmin is a versatile hosting platform that supports a wide range of games, so you can host virtually any game you want. Officially supported titles include:
