# Supported Games

TCAdmin v3 can host almost any dedicated server, and these <strong>{GAMES.length}</strong> games have ready-made configs in the official and community plugin repositories. Install any of them straight from the plugin repository in your game panel.

<GameGrid />

:::tip[Don't see your game?]
You can set up your own game blueprint in the panel, or contribute one to the community plugin repository so other community members can use it too.
:::
